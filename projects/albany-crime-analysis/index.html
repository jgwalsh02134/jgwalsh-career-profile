Approach

The assessment combines Uniform Crime Reporting data, department arrest logs, and investigative case notes to surface cross-functional indicators. A structured analytic pipeline in Python supports repeatable data hygiene steps, while exploratory dashboards in Observable facilitate briefings with command staff and municipal partners.

Insights reference behavioral threat triage frameworks, placing emphasis on recency, severity, and geographic concentration to accelerate investigative decision-making.
